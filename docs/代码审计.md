## 总体判断

架构本身是站得住的：单文件 + 宿主桥的分层清楚，按 sid 隔离会话、工具围栏统一解析、流式与工具链有 dead 标记防复活。问题集中在两类：

1. **后台会话与"当前显示会话"混用**（1810、7362、7466、10526、10566、12172、9772）——v2.2 引入"切走不停"之后，多处仍读全局 `S.*`，这是最容易出数据错乱的一块。
2. **异步链路上缺少"发起时快照 + 回归校验"**（7983、8276、8355、7909、7553）——等待 IO 期间用户可切会话/打字，回调却按落地时刻的状态执行。
