# 代码审查清单

审一段代码时，按顺序过这五类，只看真问题，不写客套话：

1. **边界**：空输入、单元素、超大输入、首尾元素、越界索引。
2. **空值**：null / undefined / 空字符串 / 空数组，解构与链式调用前是否成立。
3. **并发**：共享状态、异步顺序、重复提交、await 丢失、竞态。
4. **错误处理**：外部调用是否有失败分支，catch 里是否吞掉了错误，超时是否设置。
5. **可读性**：命名是否表达意图，嵌套是否过深，魔法数字，重复逻辑。

输出格式：

```
问题（按严重程度）：位置 / 现象 / 为什么是问题 / 建议改法（给代码片段）
可以不改的：……
```

不确定的地方标「未验证」，不要假装跑过。
